# TheGoodTools
Some good tools that will help in your every day tasks in your projects.

The Good Tools is a lightweight and efficient set of utilities designed to speed up your daily workflow inside Unreal Engine. It helps you maintain clean, organized, and consistent projects with automated asset and scene-management tools with just a click of a button.

**Included Tools**

 1. Rename Selected Assets – Batch-rename assets using custom patterns.
 2. Clean Up Folder – Remove unused or unnecessary items in any folder.
 3. Check Power of Two – Verify that texture sizes follow power-of-two standards.
 4. Add Prefixes for Assets – Automatically assign correct prefixes based on asset type.
 5. Remove Unused Assets – Detect and delete unreferenced assets safely.
 6. Duplicate Assets With Naming – Duplicate assets with clean, sequential naming.
 7. Organize World Outliner – Auto-sort and structure actors in the World Outliner.
 8. Delete Null Static Mesh Actors – Find and remove invalid/static mesh-less actors in the scene.
